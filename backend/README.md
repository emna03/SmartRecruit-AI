# Backend — Spring Boot

API REST principale de SmartRecruit AI (Java 21, Spring Boot 3, Maven Wrapper).

Responsabilités : sécurité JWT et rôles, logique métier, persistance MySQL (JPA),
appels au service IA FastAPI.

Structure des packages : voir `docs/architecture.md` (section 3.1).
